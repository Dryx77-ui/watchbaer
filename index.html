Watchbär

Streaming-Daten: JustWatch über TMDB · Tonspuren: Streaming Availability API
Diese App nutzt die TMDB-API, ist aber nicht von TMDB unterstützt oder zertifiziert.

Einstellungen

Die Schlüssel bleiben nur auf diesem Handy gespeichert.

So bekommst du den TMDB-Schlüssel

  1. Auf themoviedb.org/signup kostenlos registrieren und die E-Mail bestätigen.
  2. Oben rechts auf dein Profilbild → Einstellungen → links API.
  3. Einen Schlüssel beantragen („Developer“), Formular ausfüllen (Zweck: private App).
  4. Den API-Schlüssel kopieren und oben einfügen.

So bekommst du den RapidAPI-Schlüssel

  1. Auf die Streaming-Availability-Seite gehen und kostenlos registrieren.
  2. Subscribe to Test / Pricing → den kostenlosen Plan „Basic“ wählen.
  3. Im Bereich „Endpoints“ steht rechts X-RapidAPI-Key – den kopieren und oben einfügen.

Gratis-Plan: 100 Abfragen pro Tag, eine Abfrage pro Titel. Die App fragt Tonspuren pro Titel höchstens alle 12 Stunden neu ab und meldet sich, falls das Limit mal erreicht ist.

Sicherung deiner Liste
